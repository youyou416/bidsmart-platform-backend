# 权限与后续扩展契约

本期基础实现保留类型化扩展接口，并以合成上下文测试规则，不建设具体采购业务表、单据或管理页面。控制器只处理请求/响应，服务层执行规则，JdbcTemplate 使用参数化查询；新增接口需明确权限码与服务端验证，不仅隐藏前端入口。

## 角色、资源及实时权限

`PermissionCalculator` 计算多角色有效权限并集，每个角色为自身授权与有效父角色授权合并，检测角色循环和非法父节点。验证示例：子角色 A/B/C 加父角色 B/C/D 得到 A/B/C/D；父角色更新为 C/E 后下一次计算为 A/B/C/E。人员数据范围、采购类型和物资类别仍来自人员配置，不随角色并集扩大。

`PermissionService` 每次请求读取当前配置，不把权限永久缓存到会话中。`sys_role_resource` 只存自有授权，计算结果区分继承来源。合成管理员通过明确授权工作，仍受资源状态和数据范围约束。资源目录父子关系与角色继承分别处理；不会因勾选父菜单名称自动扩大操作授权。

资源支持目录/菜单/按钮、父节点、排序、路由、受控组件、图标、显示状态、启用状态、权限码。当前只登记框架说明组件 `Home`。新增资源只有在对应代码页面开发并登记后才有意义；无需铺设几十个空业务菜单。禁用资源不能手工输入路由绕过，隐藏只影响展示。

## 部门与企业范围

`DepartmentScopeCalculator` 验证部门树，指定部门和本部门均包含合法全部下级。四类范围：

| 类型 | 规则 |
| --- | --- |
| `SELF_AND_SPECIFIED` | 本人创建/申报的数据及指定部门范围 |
| `DEPARTMENT` | 本部门及下级 |
| `ALL_DEPARTMENTS` | 全部合法部门 |
| `DEPARTMENT_AND_SPECIFIED` | 本部门及下级，与指定部门及下级并集 |

`BusinessContext` 携带合成或未来适配器确定的创建/申报者、部门、企业、采购类型、物资类别，`DataScopeService` 根据登录上下文作判断。未来业务必须确定真实归属字段；“本人”不能直接换成采购员字段。不存在的部门、循环或非法父节点不能扩大范围。

采购方 `BUYER` 与供应商 `SUPPLIER` 保留独立身份上下文。供应商先按登录身份绑定 `enterpriseId` 限定企业，再检查功能权限；请求体不能修改登录企业/用户/部门扩大范围，不将不同企业范围并集。

## 查看与办理

`AuthorizationDecision` 返回明确允许/拒绝原因。查看需角色查看权限和数据范围；不额外要求采购类型/物资类别。办理需要角色操作权限、采购类型、数据范围、物资类别同时满足。物资类别空集合拒绝办理；采购类型空集合返回未配置/拒绝，不能推断为全部。管理员同样遵守。

采购类型及物资类别表只保存未来授权代码，不生成其管理模块。导出/打印归类、采购类型空配置的业务含义、具体单据归属字段、模板变更和审批执行规则需未来确认，不预建完整 CRUD、流程引擎、动态脚本或金额公式执行能力。

## 字典、参数与业务配置预留接口

`extension.ConfigurationCatalog` 是文档允许的类型化预留契约，当前没有注册实现 Bean 或 HTTP 入口，也未创建字典/参数/业务配置管理表或页面。未来适配器分别实现：

| 方法 | 返回数据 |
| --- | --- |
| `dictionary(dictionaryCode, authenticatedCaller)` | `List<DictionaryItem>`，每项仅 `code`、`label`、`enabled` |
| `parameter(parameterKey, authenticatedCaller)` | `Optional<String>`，参数不存在时明确为空 |
| `businessConfiguration(configurationCode, authenticatedCaller)` | `Map<String,String>`，受控数据配置 |

`authenticatedCaller` 类型为服务端生成的 `PermissionSnapshot`。适配器必须校验字典/配置代码及参数键白名单，再按调用者实际授权返回最小数据；客户端不得自行构造授权上下文。此接口只传数据，不根据值查找任意 Java 类、执行表达式、脚本或 SQL，也不暴露环境变量、凭据、密钥或完整服务端配置。公开界面配置仍由已有专用白名单接口提供，不能用未来通用参数接口替代。

## 会话和国密扩展

`SessionStore` 为未来数据库/缓存共享留适配接口；当前 Servlet 内存会话仅单实例。更换存储时须验证会话撤销、账号停用、绝对超时、CSRF 与并发行为，不能直接复制本机配置声称共享可用。

SM4 keyId/密钥环/持久 nonce 状态必须受控注入，未来字段适配器明确 AAD、轮换和备份恢复规则；SM2 明确用途、曲线参数、用户标识与互操作编码。没有默认业务字段或通用公开加密 API。满足国密算法工具要求不替代传输及部署验证。
