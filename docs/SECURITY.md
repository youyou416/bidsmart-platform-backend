# 安全机制与边界

本期默认仅隔离本机研发。Spring Boot 2.5.3 是用户固定的对齐版本，构建成功不代表适合直接开放公网。正式接入前须完成依赖风险、真实数据库、HTTPS/国密传输及部署配置审查，参见 [依赖说明](DEPENDENCIES.md) 和 [验证记录](VALIDATION.md)。

## 认证、Cookie 与 CSRF

Spring Security 5.5.1 管理单实例服务端会话，安全随机会话标识由容器生成。`BIDSMARTSESSION` Cookie 为 HttpOnly、SameSite=Lax、路径 `/`，不设置宽泛 Domain；prod 使用 Secure。本机 dev 明确选择 HTTP 时可关闭 Secure。Boot 2.5.3 通过 Tomcat CookieProcessor 设置 SameSite，不使用新 Boot 才支持的配置假设。会话空闲默认 30 分钟、绝对时长 8 小时；重启失效。

JSON 登录执行认证策略、轮换会话并保存 SecurityContext；服务端每次受保护请求重新检查账户状态/密码版本并读取当前授权。登出销毁服务端会话；改密撤销该用户旧会话并要求重新登录。没有 JWT、公开注册、找回密码或共享缓存。`SessionStore` 仅保留未来存储适配点，不能据此宣称多实例共享已实现。

浏览器先调用 CSRF 握手接口，写请求携带返回的指定请求头。登录、退出和改密均开启 CSRF 检查；认证后/退出后重新握手。CSRF 握手防缓存、限制来源与频率。明确来源 CORS 配合凭据请求，不信任任意来源或任意 `X-Forwarded-For`；本机 Vite 代理是默认联调方式。

初始账号由明确开启的初始化过程创建，无固定账户密码、不覆盖已有账户。首次登录只能完成自身改密和退出。密码为 12～128 Unicode 字符，不裁剪、不去除首尾空格；缺失账户、禁用账户和错密码返回统一提示。按账户和真实来源地址限流，默认 15 分钟内连续 5 次失败后限制 15 分钟，避免永久锁定。成功登录只重置相应账户失败计数；来源地址聚合失败窗口保留，防止用有效账户反复清除跨账号暴力尝试计数。

## 授权与配置安全

管理员也采用显式资源授权；不存在通配权限或名称放行分支。人员多个角色合并功能权限，角色动态继承在每次受保护请求计算；继承权限不永久复制进自有授权。禁用资源和非法树关系拒绝授权。除精确白名单基础端点外，新API处理器缺少所需权限声明即403。菜单可见性仅影响展示，隐藏按钮不是接口安全边界。

组件标识只能映射前端登记的 `Home` 等受控白名单，不执行数据库中的脚本、表达式、任意类名或远程组件。部门范围、采购类型、物资类别和供应商企业隔离不随多角色并集扩大。业务查看与办理的可组合接口只用于合成上下文验证，未提供采购业务 API。

## 国密工具

密码存储为版本化 PBKDF2-HMAC-SM3 派生串：版本、工程默认 600000 迭代、16 字节随机盐、32 字节结果。实现显式使用 Bouncy Castle SM3Digest，恒定时间比较，拒绝未知算法/版本和无效参数。不是一次 SM3、前端摘要或可逆 SM2/SM4 密码存储。迭代数是工程默认，目标机器须实测耗时；参数升级需版本化校准。

SM4-GCM 工具使用 128 位密钥、96 位 nonce、128 位标签。封装保存算法、版本、keyId、nonce、密文与标签；字段用途/记录身份通过必填 AAD 绑定，篡改或错密钥失败。密钥环必须显式注入，旧 keyId 可解密，切换 active keyId 执行轮换；不得将同一密钥当作多个独立轮换密钥。持久 nonce 分配器在加密前锁定并持久化单调计数状态；目录须在仓库外受控保存。禁止在复用旧密钥时删除、回滚或复制 nonce 状态到并发未协调的实例，轮换密钥/状态应作为同一运维过程。当前单实例实现不自动支持多主机全局 nonce 分配。

SM2 签名扩展明确使用 SM3withSM2、调用者提供的用户标识和 ASN.1 DER 签名字节；密钥与参数由受控调用者提供。没有对外通用加解密接口，不强制自定义每请求加密。

密钥、初始密码与数据库密码不出现在源码、前端、日志或版本化配置中。算法自检和必要密钥缺失时拒绝对应能力，不静默换算法。应用层工具不证明全链路国密、国密 TLS 或商用密码合规认证；这些分别需要协议、证书、网关、浏览器及数据库链路验证。

## 审计与信息最小化

认证审计记录 LOGIN_SUCCESS/LOGIN_FAILURE/LOGIN_RATE_LIMITED；操作审计包括 LOGOUT、PASSWORD_CHANGED、FIRST_PASSWORD_CHANGED、AUTHORIZATION_DENIED、BOOTSTRAP_CREATED、SESSION_REVOKED。字段仅事件、合法用户标识、结果、来源地址、traceId 与 UTC 时间，不记录原始账户输入、密码、派生串、Cookie、CSRF 令牌、私钥、请求体或解密结果。未知数据库故障向客户端返回脱敏提示，不返回 SQL、连接串、内部栈。

框架审计表按配置保留默认 30 天，每天03:00 UTC清理，清理只能作用于自身两张日志表。密码修改/初始账户创建与对应数据库审计写入采用事务；真实OceanBase事务行为仍需接入测试，Mock仓库不能证明它。test启动要求显式独立库/主机/业务账号与验证身份的TLS，拒绝dev库hr_score_dev和root/sys；prod同样拒绝所有root账号形式，不能用root@业务租户绕过。运行日志/文件按主机权限与保留策略管理，不作为交付数据。研发全用合成资料，不导入真实人员、证照、电话或生产单据。依赖与脚本保持 TLS、包签名/摘要验证，不通过关闭检查来修复下载失败。
